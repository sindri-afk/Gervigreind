what does estimating pi do?
well it is a probability distribution over the initial states
it is basically estimating what phoneme is most likely to be spoken at the beginning of an utterance
and this is important for the HMM because when the HMM starts (time t = 0), it needs to know:
    - Where do I begin?

which is what pi gives us: the probability of starting in each phoneme state

ex: 
[28, 28, 16, ...]   # starts with 28
[5, 5, 5, ...]      # starts with 5
[28, 16, 16, ...]   # starts with 28
[5, 2, 2, ...]      # starts with 5
[28, 28, 28, ...]   # starts with 28
count: state 28 --> 3 times
       state 5 --> 2 times

What phoenems tend to start in speech


A in HMM:
count how often state i goes to state j, then normalize per row to get probabilities


Sigma in HMM: 
for each state i, calculate the mean and covariance of the observations that are labeled with that state
This gives us the parameters of the Gaussian distribution for each state, which is used to calculate the likelihood of observing a particular feature vector given that state.

Basically:
for each state (phoneme), we want:
    not just average (mu), but spread and relationship between features (covariance)

Forget 39 features, imagine:
X = [
  [1, 2],
  [3, 4],
  [5, 6]
]

each row = one sample (observation)
each column = one feature 

What covariance captures:
it tells you:
    - how much feature 1 varies
    - how much feature 2 varies
    - how much feature 1 and feature 2 vary together (covariance)

what does np.cov do?
ex: cov = np.cov(X, rowvar=False)
important: rowvar=False means that rows are observations and columns are features

Output: for 2 features you get:

[ [var(feature1),  cov(f1, f2)]
  [cov(f2, f1),   var(feature2)] ]

Example result:
[ [4, 4]
  [4, 4] ]

this means: 
    - both features vary the same
    - they are strongly correlated (covariance is high)

In our case:
X.shape = (num_frames_for_state, 39)
so:
np.cov(X, rowvar=False) returns: (39, 39) covariance matrix for that phoneme


what is np.eye?
it creates an identity matrix of size n x n
[1 0 0]
[0 1 0]
[0 0 1]
in our case:
np.eye(self.feature_dim) creates a 39 x 39 identity matrix

what is feature_dim?
from our data features.shape = (T, 39)
so feature_dim = 39

what is self.reg? 
this is a small number added to the diagonal of the covariance matrix to ensure it is positive definite and invertible
it means: "add a tiny bit of noise to the diagonal"
why do we add it?
because sometimes the covariance matrix can be singular (not invertible) if the features are highly correlated
And later we will compute: Gaussian --> requires the inverse of the covariance matrix
